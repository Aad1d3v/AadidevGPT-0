Under the hood

How it actually works

The real mechanics behind the features — no magic, just code.

⚡

Streaming

Every reply streams token-by-token over Server-Sent Events. The Flask backend pipes the model's output straight to your browser, where it renders as live markdown — no waiting for a full answer.

🧠

Memory

Tap "Remember this" on any reply and that fact is saved to your account. On every future message it's injected into the model's context — "Forget all" wipes it instantly.

📁

Project context

Name a project once and its description rides along in the context of every request, so AadidevGPT-0 keeps it in mind across all your chats. A pill in the header shows what it's tracking.

🤖

Model 04Aadi

04Aadi is the application layer — the prompt system, personas, modes, and memory built by Aadidev. The model underneath is a hosted open-source LLM (gpt-oss-20b) called through the Groq API.

The process

Problems I actually solved

Real bugs from real deploys — and how they got fixed.

🗄️

Chats kept vanishing

Render's free tier wipes its filesystem on every redeploy, so SQLite accounts disappeared. I migrated the database to PostgreSQL — accounts and chats now survive redeploys and restarts.

🔑

Logins wouldn't stick

Sessions died on every server restart because the signing key wasn't persisted. The key now lives on disk, so sign-ins survive restarts.

👥

Duplicate accounts

Signing up twice with the same email created junk accounts. A unique constraint now rejects duplicates with a clear message.

🎟️

One free chat, then sign-in

Guests get exactly one free chat per browser; signed-in users get unlimited. The whole limit lives in one backend check.

Privacy

Your data, straight up

You're storing chats, memory, and projects with us — here's exactly what that means.

🔒

Tied to your account

Chats, memory, and project context belong to your account. They're only visible while you're signed in — signing out hides everything.

🗑️

Full deletion

Delete your account and everything goes: chats, memory, projects, and your profile — permanently, no backups kept.

Guest chats aren't stored
